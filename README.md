# Samriddhi Krishi and Poultry Pvt. Ltd. — Single-Page Website

This is a static, responsive single-page website built from the supplied master prompt.

## Files
- `index.html` — complete one-page site, SEO metadata, semantic structure and structured data.
- `styles.css` — responsive visual system and layout.
- `script.js` — smooth navigation, mobile menu, active section highlighting, crop tabs, gallery filtering/lightbox, product modal and frontend enquiry handling.

## Run locally
Open `index.html` in a browser, or serve the folder with a simple local web server.

## Important
The website uses temporary external agricultural imagery from Unsplash. Replace these image URLs with genuine Samriddhi photographs before launch if available.

The enquiry form currently prepares an email using `mailto:`; no backend endpoint is connected. This is intentionally stated on the form and does not falsely claim server-side submission.

## Single-page rule
There is only one HTML page and no internal routes. Navigation uses section anchors such as `#about`, `#services`, `#products`, and `#contact`.
